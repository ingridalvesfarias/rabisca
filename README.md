# Rabisca ✎
Quadro branco em HTML + CSS + JS puro (Canvas 2D), inspirado na ideia do Excalidraw. Projeto de estudo.

Como usar: abra `index.html` no navegador (sem instalar nada).

Ferramentas e atalhos: V selecionar · R retângulo · O elipse · D losango · L linha · A seta · P lápis · T texto · E borracha · Ctrl+Z desfazer · Ctrl+Y refazer · Delete apaga o selecionado.

Para estudar (ordem sugerida em app.js): lista de elementos → render() → eventos de ponteiro → histórico (undo/redo) → temas com variáveis CSS.

Ideias para evoluir: zoom e pan, redimensionar elementos, camadas, salvar/abrir arquivo .json, colaboração com Firebase.
